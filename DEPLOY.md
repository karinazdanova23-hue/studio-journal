# Единый журнал — сервер

Это серверная версия «Единого журнала»: Node.js/Express + SQLite (файл-база, как у трекера керамики). В отличие от версии для Claude, здесь пароли проверяются на сервере, а не в браузере — это нужно, раз сайт будет доступен всем в интернете.

## Файлы в этой папке

- `server.js` — весь сервер (сайт + API + вход + база данных).
- `package.json` — список зависимостей.
- `public/index.html` — само приложение (интерфейс).
- `.gitignore` — какие файлы НЕ загружать в GitHub (папку `node_modules` и файл базы данных `data/`).

## Шаг 1. Загрузка на GitHub

Точно так же, как делали с керамикой — через перетаскивание файлов в браузере, без командной строки:

1. Зайдите на [github.com](https://github.com) под своим аккаунтом (`karinazdanova23-hue`).
2. Создайте новый репозиторий: кнопка **New** → название **`studio-journal`** → **Create repository**.
3. На странице пустого репозитория нажмите **uploading an existing file** (или значок загрузки файла).
4. Перетащите в окно браузера **все файлы и папки** из этой папки, кроме `node_modules` и `data` (их не должно быть — они и так исключены `.gitignore`, если создавали архивом, просто не загружайте эти две папки, если увидите их у себя).
5. Внизу страницы нажмите **Commit changes**.

## Шаг 2. Подключение к Таймвебу

1. Зайдите в панель Таймвеба → раздел **«Приложения»** (App Platform).
2. Нажмите **Создать приложение** (или аналогичную кнопку).
3. Выберите источник — **GitHub**, подключите аккаунт (если ещё не подключён) и укажите репозиторий **`studio-journal`**.
4. Таймвеб должен сам определить, что это Node.js-приложение (по файлу `package.json`), и предложить команду запуска — она уже прописана: `npm start`.
5. **Обязательно добавьте переменную окружения** (раздел «Переменные окружения» / Environment Variables при настройке):
   - Имя: `SESSION_SECRET`
   - Значение: любой длинный случайный набор символов (например, надёжный пароль на 30+ символов) — это внутренний секретный ключ сервера для защиты входа, никому его не сообщайте.
6. Запустите деплой.

## Шаг 3. Первый вход

1. Откройте адрес, который выдаст Таймвеб для приложения.
2. Увидите экран входа со списком из 6 стандартных ролей (Руководитель, Ассистент и т.д.) — паролей пока ни у кого нет.
3. **Сначала задайте пароль Руководителю** — выберите его в списке, придумайте пароль, нажмите «Задать пароль и войти».
   - Важно сделать это первым, до пароля любого другого сотрудника — иначе он окажется единственным, у кого есть доступ к разделу «Сотрудники», и придётся просить меня чинить это вручную через базу данных.
4. Дальше — как обычно: заходите в «👥 Сотрудники» и задаёте пароли остальным.

## Обновление кода в будущем

Если попросите что-то доработать — я подготовлю обновлённые файлы, а вы так же перетащите их поверх старых в тот же репозиторий на GitHub (кнопка **Add file → Upload files**, с заменой). Таймвеб подхватит изменения автоматически при следующем деплое (либо нажмёте «Передеплоить» в панели, если он не запускается сам).
